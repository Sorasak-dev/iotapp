# รายงานการทดสอบระบบ IoT Backend

## ภาพรวม

ได้ทำการพัฒนา Test Suite แบบครบวงจรสำหรับระบบ Backend โดยใช้ **Unit Testing** และ **Integration Testing** เพื่อตรวจสอบความถูกต้องและความน่าเชื่อถือของระบบ

---

## เทคนิคการทดสอบที่ใช้

### 1. Unit Testing
ทดสอบแต่ละ component แยกส่วน โดยไม่ขึ้นกับส่วนอื่น

### 2. Integration Testing
ทดสอบการทำงานร่วมกันของหลาย components

### 3. In-Memory Database Testing
ใช้ **MongoDB Memory Server** แทนฐานข้อมูลจริง

### 4. API Testing
ใช้ **Supertest** ทดสอบ HTTP endpoints

## 3. User Controller Testing (13 tests)

**ทดสอบ API ของผู้ใช้ว่าทำงานถูกต้องไหม**

### ✅ ทดสอบดูข้อมูล Profile (GET)
- ดูข้อมูลตัวเองได้ (ต้องมี token)
- ไม่มี token → ขึ้น error 401
- Token ผิด → ขึ้น error 401
- Token หมดอายุ → ขึ้น error 401

### ✅ ทดสอบแก้ไข Profile (PUT)
- แก้ไขชื่อ, เบอร์โทร, เพศได้
- แก้ไขรูปโปรไฟล์ได้
- แก้ไขแค่บางฟิลด์ได้
- ไม่มี token → ห้ามแก้ไข

### ✅ ทดสอบเปลี่ยนรหัสผ่าน (POST)
- เปลี่ยนได้ถ้ารหัสเก่าถูก
- รหัสเก่าผิด → ห้ามเปลี่ยน
- รหัสใหม่ 2 ครั้งไม่ตรงกัน → ห้าม
- ไม่ใส่ข้อมูลครบ → ห้าม
- ไม่มี token → ห้ามเปลี่ยน

**ผลลัพธ์: ✅ ผ่าน 13/13 tests (100%)**

## 4. Device Controller Testing (17 tests)

- แก้ไขแค่บางฟิลด์ได้

### ✅ ทดสอบลบอุปกรณ์ (DELETE)

- ลบ ID ที่ไม่มี → error 404
